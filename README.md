# industry
Название: Industry Ecology Map
URL: https://ecologyoilgaz.github.io/industry/
Фокус: цемент, металлургия, химия, горнодобыча, стройматериалы, машиностроение.
Проблемы: выбросы CO₂, пыль PM2.5, токсичные отходы, хвостохранилища, кислые стоки, деградация почв.
Спутниковые источники: Sentinel-5P (NO₂, SO₂), Sentinel-2 (пыль, деградация), VIIRS (факелы на заводах), Sentinel-1 (просадка грунта).
Токены и кошельки: те же, что и в других секторах (€ECO, €GREEN, €20, $ONE).
